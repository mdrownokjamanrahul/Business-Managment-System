# হিসাব - ব্যবসায়িক ম্যানেজমেন্ট PWA

## 📁 ফাইল তালিকা
- `index.html` — ড্যাশবোর্ড
- `add-product.html` — পণ্য যোগ ও ইডিট
- `sell.html` — বিক্রয়
- `sales-history.html` — বিক্রির হিস্টরি
- `due-accounts.html` — বাকি হিসাব
- `stock.html` — স্টক দেখুন
- `reports.html` — রিপোর্ট ও ইনভয়েস
- `settings.html` — সেটিংস
- `sw.js` — Service Worker (PWA)
- `manifest.json` — PWA Manifest
- `offline.html` — অফলাইন পেইজ
- `shared-styles.css` — শেয়ার্ড CSS
- `icons/` — PWA আইকন ফোল্ডার

## 🚀 GitHub Pages-এ Deploy করুন (বিনামূল্যে)

### ধাপ ১: GitHub Account
1. https://github.com এ যান
2. নতুন account তৈরি করুন (বিনামূল্যে)

### ধাপ ২: নতুন Repository তৈরি
1. "New repository" ক্লিক করুন
2. নাম দিন: `sakib` (অথবা যেকোনো নাম)
3. **Public** রাখুন
4. "Create repository" ক্লিক করুন

### ধাপ ৩: ফাইল আপলোড
1. "uploading an existing file" ক্লিক করুন
2. সব ফাইল ও `icons` ফোল্ডার drag করুন
3. "Commit changes" ক্লিক করুন

### ধাপ ৪: GitHub Pages চালু করুন
1. Repository → Settings → Pages
2. Source: "Deploy from a branch"
3. Branch: `main`, Folder: `/ (root)`
4. Save

### ধাপ ৫: লিংক পাবেন
`https://আপনার-username.github.io/sakib/`

## 📲 ফোনে Install করুন

### Android (Chrome):
1. সাইটে যান
2. Chrome মেনু (⋮) → "Add to Home screen"
3. "Install" ক্লিক করুন

### iPhone (Safari):
1. Safari-তে সাইটে যান
2. Share বাটন (⬆️) → "Add to Home Screen"
3. "Add" ক্লিক করুন

## ⚠️ গুরুত্বপূর্ণ
- PWA কাজ করতে **HTTPS** লাগবে (GitHub Pages স্বয়ংক্রিয়ভাবে দেয়)
- `localhost` এও কাজ করে (development)
- Firebase ডেটা সবসময় সার্ভারে থাকে
